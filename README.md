# 🧮 BMI Calculator

A modern and responsive BMI Calculator web application built using HTML, CSS, and JavaScript.

## 🚀 Live Demo

https://silambarasanc199-jpg.github.io/bmi-calculator/

## ✨ Features

- Calculate Body Mass Index (BMI)
- Height input in centimeters
- Weight input in kilograms
- BMI result displayed up to 2 decimal places
- BMI category classification
- Input validation
- Rejects zero and negative values
- Validates realistic height and weight ranges
- Clear button to reset the calculator
- Responsive mobile-friendly design
- Modern futuristic user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📊 BMI Categories

| BMI Range | Category |
|-----------|----------|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal weight |
| 25.0 – 29.9 | Overweight |
| 30.0 and above | Obesity |

## 📐 BMI Formula

BMI is calculated using:

`BMI = Weight (kg) / Height² (m)`

Example:

`Height = 170 cm`
`Weight = 65 kg`

`BMI = 65 / (1.70 × 1.70)`

`BMI ≈ 22.49`
